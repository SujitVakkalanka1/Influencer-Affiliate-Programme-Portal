INFLUENCER AFFILIATE PROGRAMME PORTAL - MONGODB READY VERSION

This version uses MongoDB + Mongoose. No MySQL is used.

BEFORE RUNNING:
You need MongoDB in one of these ways:

OPTION A - Local MongoDB:
1. Install MongoDB Community Server.
2. Make sure the MongoDB service is running.
3. Keep backend/.env like this:
   MONGO_URI=mongodb://127.0.0.1:27017/influencer_affiliate_portal

OPTION B - MongoDB Atlas:
1. Create a free MongoDB Atlas cluster.
2. Copy your connection string.
3. Paste it into backend/.env as MONGO_URI.

RUN PROJECT:
1) Double-click:
   1-install-all.bat

2) Double-click:
   2-start-backend.bat

   Wait until you see:
   MongoDB connected
   MongoDB database ready
   Server running on port 5000

3) Double-click:
   3-start-frontend.bat

4) Open:
   http://localhost:5173

ADMIN LOGIN:
Email: admin@portal.com
Password: password

TEST FLOW:
1. Register a new influencer.
2. Login with that influencer.
3. Generate an affiliate link from an active campaign.
4. Record a sale/conversion.
5. Request payout.
6. Login as admin and approve payout.

All users, campaigns, affiliate links, clicks, conversions, commissions, and payouts are stored in MongoDB collections.
